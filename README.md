## 📚 The 10 Strata Curriculum Sectors

* **Sector 0: Calibration Drop** — Sequential Python execution & methods (`rover.drill()`, `rover.move_down()`, `rover.collect()`).
* **Sector 1: Basalt Trench** — Loops with `for` and `range()` to blast through 6 rock layers with zero repeated code.
* **Sector 2: Magma Fault Line** — Optical radar scanning (`rover.scan_down()`) & `if / else` conditionals to divert around molten hazards.
* **Sector 3: Geode Caverns** — Python lists (`rover.cargo`), collection tracking, and `len()` quota checks.
* **Sector 4: Reactor Power Matrix** — Python dictionaries (`rover.systems['torque'] = 90`) to overclock drill systems and pierce heavy titanium blast doors.
* **Sector 5: Core Extraction Protocol** — Defining reusable functions (`def harvest_tier():`) to clear deep branching chambers.
* **Sector 6: Electromagnetic Void** — State loops (`while rover.y < 6:`) and power cell energy conservation.
* **Sector 7: Mineral Sifter** — List comprehensions (`[x for x in rover.cargo if "Emerald" in x]`) for single-line mineral filtration.
* **Sector 8: Obsidian Labyrinth** — Python tuples `("DOWN", 2)` and path coordinate list iteration to navigate complex mazes.
* **Sector 9: The Planetary Singularity** — The Master Protocol: autonomous multi-system orchestration combining dictionaries, loops, functions, and radar scans at the center of the planet!

## 🌐 Dual One-Click Deployment

### Deploy to GitHub Pages (`github.io`)
```bash
bash deploy/deploy_github.sh
```
Pushes the static `dist/` bundle to your `gh-pages` branch for instant hosting on `https://<your-username>.github.io/PythonPit/`.

### Deploy to FlaskArchitect (`flaskarchitect.com`)
```bash
bash deploy/deploy_flaskarchitect.sh
```
Uses `rsync` to drop the production build straight into your VPS `/var/www/pythonpit` directory.
